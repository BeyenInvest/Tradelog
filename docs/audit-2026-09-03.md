## 1. HOOG

### H1 — Geen CI: de 397 tests draaien nergens automatisch
Geen `.github/` map. Vercel auto-deployt vanaf main en draait `tsc -b && vite build`, dus type-errors blokkeren wél, maar de tests alleen als iemand er lokaal aan denkt. Gegeven solo-dev + parallelle Claude-sessies + de stats-motor als productkern: een merge die tsc overleeft maar een stats-invariant breekt gaat ongetest naar prod.
**Fix:** minimale GitHub Action (`npm ci` → lint → test → build) + required check op main; of goedkoper: Vercel Build Command = `npm run test && npm run build`.

### H2 — `supabase/schema.sql` substantieel gedrifted (fresh bootstrap = half-kapotte app)
Bekend als S2-2 in de vorige audit, maar de omvang is nu in kaart: schema.sql mist `periodic_reviews.periode_overzicht` (0007 — **elke periodieke review-save faalt**), de hele share-laag (`share_links` + 5 RPC's; breekt óók journal-delete via `fetchCounts`), `create_journal` (journal-builder kapot), `rename_field_option`, screenshots-bucket + storage-policies, de 0052-versie van `link_trade_to_weekly_review` (M1-a-bug keert terug), de composiet-index, en de 0036-anon-revoke-conventie. Prod is oké (migraties gedraaid); alleen verse installaties breken.
**Fix:** schema.sql bijwerken t/m 0052 (of header wijzigen naar "bootstrap = schema.sql + migraties vanaf 0007") + conventie: elke RPC/tabel-migratie werkt schema.sql mee bij.

### H3 — Landing: kernbelofte is beta-gated, copy zegt "werkt vandaag"
`landing.m.lead/lead2` + `landing.t.note` ("Al het andere op deze pagina werkt vandaag") verkopen veld-editor/presets/meerdere journals, maar die staan achter `profiles.beta_features`. Een gewone signup kan het hoofdverhaal niet uitvoeren; `m.lead2` presenteert multi-journal als bestaand terwijl het onder Pro "soon" hoort.
**Fix:** koppel de beta-flip (of default-aan voor nieuwe signups) aan de landing-deploy, óf verzacht `t.note`/`m.lead2` tot die tijd. Verwant: alle 6 CTA's → `/signup` dat hard faalt tot de README §5-rollout (bekend B6-punt — landing pas publiek als signup echt open is).

### H4 — Landing: SEO ontbreekt volledig
`index.html` heeft alleen een `<title>`: geen meta description, geen OG/Twitter-cards (geen preview-card bij delen op X/Discord), geen canonical, geen `public/robots.txt`, geen sitemap.
**Fix (hoort bij B5):** description + OG-set + og-image in index.html, robots.txt + minimale sitemap.xml (/, /terms, /privacy, /signup).
